Support für die SMILE-App (iOS / iPadOS)

Die App „SMILE“ unterstützt Lehrpersonen der Mittelschule Telfs Dr. Aloys Weissenbach im Schulalltag, bei Verhaltensrückmeldungen, Lernwerkstatt-Einträgen und Bewertungen.

Kontakt

Technischer Support & Rückfragen:
E-Mail: smile@ms-telfs.at
Einrichtung: Mittelschule Telfs Dr. Aloys Weissenbach, Telfs, Österreich

Häufige Fragen

  • Anmeldung nicht möglich / Server nicht erreichbar: Stellen Sie sicher, dass sich Ihr iPhone oder iPad im Schul-WLAN (bzw. Schul-VPN) befindet. Die Server-Adresse lässt sich auf dem Anmeldebildschirm über Server: … anpassen.
  • Erstpasswort ändern: Beim ersten Login fordert die App automatisch zur Vergabe eines persönlichen Passworts auf.
  • Face ID / Touch ID aktivieren: Lassen Sie beim Anmelden den Schalter „Für Face ID speichern“ aktiviert.
  • Datenschutz: Details finden Sie in der Datenschutzerklärung.
